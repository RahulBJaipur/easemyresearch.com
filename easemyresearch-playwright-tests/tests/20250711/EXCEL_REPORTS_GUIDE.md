## 💡 **How to Use Excel Files**

### 🎯 **Which Format to Choose?**

#### 📊 **`.xls` Files (Recommended)**
- **Full formatting**: Colors, borders, styling
- **Professional appearance**: Headers, severity coding
- **Best for**: Excel, LibreOffice Calc, Google Sheets
- **Features**: Color-coded severity (Critical=Red, High=Yellow, etc.)

#### 📈 **`.xlsx` Files (Simple)**
- **Tab-delimited format**: Basic spreadsheet compatibility
- **Smaller size**: Minimal formatting
- **Best for**: Quick imports, basic analysis
- **Features**: Clean data, easy to manipulate

### 🚀 **Opening Files**

#### **Microsoft Excel**
1. Open Excel
2. File → Open → Select `.xls` or `.xlsx` file
3. File opens with full formatting

#### **Google Sheets**
1. Go to sheets.google.com
2. File → Import → Upload file
3. Select `.xls` or `.xlsx` file
4. Choose "Replace spreadsheet" or "Create new spreadsheet"

#### **LibreOffice Calc**
1. Open LibreOffice Calc
2. File → Open → Select file
3. File opens with formatting preserved

#### **Apple Numbers**
1. Open Numbers
2. File → Open → Select file
3. File imports with basic formatting
